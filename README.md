## Core Marketplace Flows to Demonstrate
1. **General Public (Demand Side):** Post a service/job request (e.g., Legal, Auto Mechanic, Plumbing, Tax/Accounting) with location and **willingness-to-pay budget (KES)**.
2. **Service Providers (Supply Side):**
   - Create provider account & top up **M-Pesa Wallet** (minimum **KES 600** onboarding deposit).
   - Set **minimum & preferred job price points** to filter out mismatched leads.
   - Receive matched leads within price band and unlock verified customer contact details at **KES 200 per lead**.
